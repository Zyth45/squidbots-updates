# SquidBots updates

Releases of **SquidBots Server**, the launcher that runs a Conquest of Azeroth server with playerbots on your own PC,
built from your own game client (no game data is distributed).

- **Download the launcher**: [`SquidBots-Server-Setup.exe`](https://github.com/Zyth45/squidbots-updates/releases/download/launcher/SquidBots-Server-Setup.exe) (Windows, x64)
- **Latest CoA Bots release and its notes**: [releases/latest](https://github.com/Zyth45/squidbots-updates/releases/latest)
- **Discord** (help, news, bug reports, ideas): https://discord.gg/DTJceaG9Ky

Once installed, the launcher keeps everything up to date by itself: the server (CoA Bots), the launcher, the
SquidBots addon and the dashboard. Every update is signed and a backup is made before the server is updated.

## What is in the releases

| Release | Content |
|---|---|
| `vX.Y` | A CoA Bots version: its notes, the server package and the update from the previous versions |
| `launcher` | The launcher installer and its signed update files |
| `components` | The SquidBots addon and the dashboard, offered by the launcher |
| `mmaps` | The bots' navigation maps, a download that saves building them on your PC |
